# Plain Text Editor

A simple and user-friendly **Plain Text Editor** developed using **Qt and C++**.

## Features

- Create a new file
- Open an existing text file
- Save a file
- Save As
- Undo and Redo
- Cut, Copy and Paste
- Select All
- Find text
- Change font
- Change text color
- Highlight text
- Zoom In and Zoom Out
- Reset Zoom
- About section
- Keyboard shortcuts
- Resource icons for menu actions

## Technologies Used

- C++
- Qt
- Qt Creator
- Qt Widgets

## Project Structure

- `main.cpp` – Application entry point
- `mainwindow.cpp` – Main application logic
- `mainwindow.h` – Main window declarations
- `resources.qrc` – Application resource icons
- `PlainTextEditor.pro` – Qt project configuration

## How to Run

1. Clone or download this repository.
2. Open `PlainTextEditor.pro` in Qt Creator.
3. Configure the Qt kit.
4. Build the project.
5. Run the application.
